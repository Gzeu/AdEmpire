Systems

Everything is simulated.

Every number on screen is calculated. No static values — every campaign, event, and rivalry runs through real math.

Reach × CTR × Conversions × AOV → Agency fee. Channel modifiers stack with seasonal events, industry bonuses, and staff skill.

Tech Stack

Pure C++. Zero engine overhead.

ImGui runs the entire UI in immediate mode. GLFW handles windowing. Everything else is custom simulation logic.

Ready to build your empire?

Clone the repo, run four commands, and you're in the game.

# Clone with ImGui submodule
git clone --recurse-submodules https://github.com/Gzeu/AdEmpire.git
cd AdEmpire && mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release && make -j$(nproc)
./AdEmpire
